# 10x Editor palettes

These are the stock color schemes from Stewart Lynch's
[10x Editor](https://10xeditor.com), copied from the upstream repository:

<https://github.com/slynch8/10x/tree/main/ColorSchemes>

Each `*.10x_settings` file is the original 10x settings format. The generators
in this repository parse the `Language.*`, `Editor.*` and `UI.*` roles and map
them onto the shared theme palette.

**Sunset** is the 10x default color scheme. The others are selectable in
10x via `Settings > Color Scheme`.
